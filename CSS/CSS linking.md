1. CSS Linking
CSS linking means connecting CSS rules with an HTML document so that the HTML elements can be styled.
There are three ways to apply CSS:
1. Inline CSS
CSS is written directly inside the HTML element using the style attribute.
Advantage: Useful for quick changes.
Disadvantage: Difficult to maintain in large websites.
2. Internal CSS
CSS is written inside the <style> tag within the HTML document.
Advantage: Useful when styling a single webpage.
Disadvantage: CSS cannot be easily reused across multiple pages.
3. External CSS
CSS is written in a separate .css file and linked to the HTML document.
Advantage: Easy to maintain, reusable, and preferred for larger projects.
Important: External CSS is generally the best approach for real-world websites.
